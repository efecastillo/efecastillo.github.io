Informacion general

Formato de entrega

Deben escribir un archivo Python con el nombre apellido.py, donde apellido debe ser reemplazado por su propio apellido. El archivo puede contener todas las funciones auxiliares que consideren necesarias, pero la respuesta a cada problema debe obtenerse al llamar a la función main de apellido.py con los argumentos especificados en cada problema.

Todas las entregas son por medio de CANVAS.

TestCases

Cada problema sera testeado con 10 entradas diferentes para chequear correctitud.

Restricciones y Consideraciones

  • No se puede importar ninguna biblioteca.
  • Tiene intentos ilimitados. Se correrá el último archivo que haya subido.

Distribución de Puntaje

Resultado Puntaje
No entrega 0
No pasa todos los tests 1
Pasa todos los tests 2
Esta entre los 5 mas rapidos de la clase 3

Bonificación (y penalización)

Se publicara una tabla con los cinco mas rapidos despues de cada problema. Esta una invitación a colaborar, no a copiarse.
